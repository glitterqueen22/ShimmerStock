# Novi Product Integration

**Version:** Phase 1 · 2026-08-07

## Principle

**CODE CALCULATES. NOVI EXPLAINS.**

- Counts, stock levels, statuses, dates, thresholds, queues, workflow state → deterministic application logic
- Explanation, prioritization, summarization, natural language, tone, decision support → Novi

Never send an entire business database to an AI model. Select minimal context.

---

## Insight Data Model

```typescript
interface NoviInsight {
  id: string;
  business_id: number;
  engine: string;               // "orders" | "inventory" | "purchasing" | etc.
  category: string;             // "stock_risk" | "order_block" | "po_suggestion" | etc.
  title: string;                // One line, plain language
  summary: string;              // 1–2 sentences. What happened and why it matters.
  severity: "urgent" | "warning" | "info" | "celebration";
  confidence: "high" | "medium" | "low";
  reasoning: string;            // Exactly how the system arrived at this insight
  recommended_action: string;   // One clear next step
  action_label: string;         // Button text
  action_link: string;          // Route to navigate to
  source_type: string;          // "inventory_check" | "order_scan" | etc.
  source_ids: number[];         // IDs of records that triggered this insight
  status: "active" | "dismissed" | "reviewed" | "approved" | "expired";
  is_demo: boolean;             // true = illustrative, never triggers real action
  created_at: string;
  expires_at: string | null;
  dismissed_at: string | null;
}
```

## Approved Action Vocabulary

**Use:**
- Show me why
- Preview
- Review
- Approve
- Dismiss
- Remind me
- Open queue
- View source

**Do NOT use:**
- Done (implies automatic resolution)
- Automatically fixed
- Automatically ordered
- Automatically refunded
- Automatically sent

|--------|-----------|-----------------|

```tsx
<NoviEngineInsight

```

- `full` — all insights in Morning Brief style with Novi avatar

## Demo vs. Live Labeling

Demo insights:
- `is_demo: true` in data model
- **Demo** badge always visible in UI
- Never trigger real external actions
- Based on `businessDna.ts` — deterministic, testable

Live insights (future):
- Generated by AI model using compact selected context
- Cached per business (reduce API calls)
- Expire after configurable window
- Cost tracked per business

## Voice Rules (in-app)

| Situation | Tone |
|-----------|------|
| Urgent stock/order issue | Calm, clear, specific — no panic |
| Purchasing suggestion | Confident, helpful — "I prepared…" |
| Customer escalation | Serious, careful — full context |
| Celebration | Warm, genuine — not over the top |
| Empty state | Curious, encouraging |

Novi never judges the owner. Novi never overwhelms. One insight at a time.
