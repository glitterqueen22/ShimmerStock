SECURITY

Security Posture

Draft for Early Access - subject to legal review.

Shopify scope posture: current Early Access connection is read-only beta and follows least-privilege scope controls.

Credential handling: credential material is stored using encrypted mechanisms with access controls.

Sessions: authenticated access uses secure HttpOnly session cookies.

Tenant-aware architecture: business data access is tenant-scoped and role-gated.

Role permissions: feature access is restricted through role-aware authorization checks.

Private staging backups: staging backup workflows are handled in controlled private environments.

Responsible reporting: report security issues to security@shimmerstock.com.
